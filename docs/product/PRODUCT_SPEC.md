# 产品规格

AgentHub 是一个以 IM 聊天为核心交互范式的多 Agent 协作平台。用户可以像使用聊天软件一样创建会话、发送消息，并与不同 Agent 单聊或群聊。

## 核心体验

- 用户通过新建对话进入任务上下文。
- 一个对话可以只包含一个 Agent，也可以在群聊模式中包含多个 Agent。
- 每个 Agent 都是聊天参与者，拥有身份、名称、头像与能力标签。
- 对话历史会作为上下文保留，支持多轮迭代。
- 用户可以 pin 关键消息，作为长期上下文输入 Agent。
- Agent 回复不只包含文本，也可以包含代码块、文件、图片、网页预览卡片、Diff 卡片和部署状态卡片。

## 优先级

### P0

- 对话列表。
- 新建对话流程。
- 单 Agent 聊天。
- 基础消息流。
- 持久化上下文。

### P1

- 多 Agent 群聊。
- Orchestrator 任务拆分与结果聚合。
- 至少两个外部 Agent 适配器。
- 代码、文件、网页预览、Diff 等内联产物卡片。

### P2

- Diff 视图与一键应用。
- 版本历史。
- 对话式局部修改。
- 部署与发布流程。
- 桌面端与移动端扩展。
