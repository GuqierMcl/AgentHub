# AI 协作记录

本目录保留 AI 辅助开发过程中形成的设计、计划和验证记录，用于说明 AgentHub 的协作方法、决策轨迹和可复用工程规范。

## 目录职责

| 目录 | 用途 |
| --- | --- |
| `specs/` | 功能设计说明，记录需求理解、边界和验收标准 |
| `plans/` | 实施计划，记录任务拆分、文件范围和验证步骤 |
| `reports/` | 验证报告，记录实际检查结果和残余风险 |

## 使用规则

- 这些文档是协作过程记录，不替代 `product/`、`architecture/` 或 `contracts/` 的事实来源。
- 当协作中形成长期有效的产品、架构或契约决策时，应提取到对应正式文档。
- 交付或答辩时，可用本目录说明 AI 协作如何帮助项目保持可追踪、可复盘和可验证。
