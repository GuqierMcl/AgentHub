# Backlog

本目录记录已经从交付路线图中提取出来的后续增强项。它不是交付阻塞清单，也不表示当前路线图未完成。

## 文档索引

| 文档 | 用途 |
| --- | --- |
| `AGENT_SIDE_CAPABILITY_BACKLOG.md` | Agent 侧能力、产物投影、权限 UI、部署、第二外部 Agent、MessagePart 恢复等交付后增强项 |

## 使用规则

- 已进入 `docs/roadmap/completed/` 的路线图不再追加新阶段。
- 新增后续能力先放入 backlog；只有进入明确实施周期时，才创建新的路线图。
- Backlog 项应写清价值、当前状态、依赖边界和建议顺序，避免只写愿望列表。
